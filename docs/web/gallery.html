Real browser captures of the frontend, grouped by app area. Each row reads left to right. Desktop (1440 × 1000) and mobile (390 × 844) are separate walkthroughs, not resized versions of one image.

Scroll each strip sideways. Click a frame for its original PNG. Shared context frames retain their original provenance and are marked “Reused view”. Browser viewport captures omit browser chrome.

Scope, evidence and limitations

The real frontend talks to local Nhost. Each layout resets only its reserved fictional gallery account and private fixtures. No production sessions, shared-data writes or database resets are used. Fonts, the browser's application date and the seeded history are pinned; Auth, database and provenance clocks remain real.

The catalog covers every web section root and representative OTP verification, Today summaries, session logging and editing, exercise details, nutrition logging and editing, progress charts, progress photos with synthetic illustrations, journal CRUD and appearance workflows. It is not exhaustive CRUD, state, tablet or browser compatibility coverage. Health/Watch actions remain native-only.

“Apple Health” markers are fictional fixture notes demonstrating read-only source presentation, not evidence of an import. Recorded backend checks do not replace the backend permission/integrity suite. Offline validation verifies retained evidence and file integrity; it does not rerun browser workflows.
